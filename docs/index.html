ENVELOPE ENCRYPTION

Per-Record AES-256-GCM

Every single entry is encrypted with its own uniquely generated 96-bit initialization vector. A compromise of one record gives zero insight into any other record in your vault.

INTEROPERABILITY

RFC 4180 CSV Importer

Migrate seamlessly. Built-in parser extracts credentials from Bitwarden, Google Chrome, 1Password, and LastPass CSV exports, including multi-line notes and 2FA secrets.

ENTROPY ANALYSIS

Cryptographic Generator

Generate non-predictable passwords with real-time Shannon entropy calculation (up to 128+ bits). Tailor character sets and filter visually ambiguous glyphs like 0/O/l/1.

PORTABILITY

Encrypted Backup Containers

Export standalone .voltrex containers encrypted with master-password-derived keys. Supports atomic rollback snapshots and cross-vault collision detection.

SYSTEM HARDENING

Inactivity Lock & Clipboard Wipe

Automatic inactivity locks engage when user interaction stops. Copied passwords are automatically purged from the operating system clipboard after 15 to 120 seconds.

AIR-GAPPED READY

Zero Mandatory Cloud Services

Voltrex Vault has no telemetry, no tracking analytics, and no remote dependencies. It functions perfectly inside completely air-gapped environments.

CRYPTOGRAPHIC RIGOR

Security by implementation, not obscurity.

How Voltrex Vault protects your credentials against physical theft, memory snooping, and tampering.

KEY HIERARCHY & ENVELOPE ENCRYPTION VERIFIED PROTOCOL
01

Master Password Input

Provided by user. Never persisted to disk in any form.

02

Argon2id KDF

64 MiB RAM, 3 iterations, 32-byte salt derives 256-bit KEK.

03

DEK Unwrapping

KEK decrypts the Vault Data Encryption Key (DEK) via AES-256-GCM.

04

In-Memory Decryption

Individual records decrypted on demand. Zeroized on lock.
